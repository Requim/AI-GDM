# 失联人员历史案例目录 v1

## 数据范围

目录保存公开灾害事件的事件级元数据，不保存姓名、电话、身份证号、住址或其他可识别个人信息。当前目录包含 Oso、Montecito 和 Mud Creek 公开滑坡/泥石流事件；每条记录带有 USGS 公共页面引用、事件日期、近似中心点、伤亡公开口径和限制说明。

目录中的 `historical_replay` 标志表示历史回放，不表示当前发生中的事件。每个事件关联一个不含个人信息的合成场景，场景只用于验证回放流程和确定性规则，不是对当年具体人员的事后概率结论。

## 来源与版本

服务启动时为目录生成 UTC 抓取时间，并把来源 URI、数据分类和空间坐标系写入领域对象。供应商页面内容不在 Git 中镜像；如果公开页面变更，目录必须重新人工核验并以新的代码提交更新，不能把缓存时间误当成事件发生时间。

## 使用限制

- 目录用于演示、历史回放和模型边界检查，不用于实时搜救指挥。
- 事件中心点是公开资料的近似位置，不代表人员位置。
- 伤亡数量遵循来源公开口径，零值可能表示页面未报告，不代表绝对无伤亡。
- 任何当前事件必须由现场信息、专业搜救人员和指挥员重新评估。
