# 失联人员历史案例目录 v1

## 数据范围

目录保存公开灾害事件的事件级元数据，不保存姓名、电话、身份证号、住址或其他可识别个人信息。当前目录包含 Oso、Montecito 和 Mud Creek 公开滑坡/泥石流事件；每条记录带有 USGS 公共页面引用、事件日期、近似中心点、伤亡公开口径和限制说明。

目录中的 `historical_replay` 标志表示公开历史案例与合成匿名场景回放，不表示当前发生中的事件。每个事件只允许关联一个不含个人信息的合成场景；案例、场景标识、场景摘要和用途声明必须在列表、详情与评估响应中保持一致。场景只用于验证回放流程和确定性规则，不是对当年具体人员的事后概率结论。

## 来源与版本

目录使用随人工核验版本固定的 UTC 审计时间，并把来源 URI、数据分类和空间坐标系写入领域对象。该时间表示目录版本的核验时间，不是供应商实时抓取时间，也不会因服务重启而更新。供应商页面内容不在 Git 中镜像；如果公开页面变更，目录必须重新人工核验并以新的代码提交更新，不能把目录加载时间或缓存时间当成来源新鲜度、事件发生时间。

## 使用限制

- 目录用于演示、历史回放和模型边界检查，不用于实时搜救指挥。
- 回放接口只接受公开案例标识且请求体必须为空，不提供姓名、电话、详细地址或真实搜救记录入口。
- 事件中心点是公开资料的近似位置，不代表人员位置。
- 伤亡数量遵循来源公开口径；来源未明确披露时返回 `null`，只有公开来源明确报告为零时才返回 `0`。
- 评估结果必须保持 `humanReviewStatus=required`，并与 `/api/v1/survival/model-card` 返回的模型版本完全绑定。
- 任何当前事件必须由现场信息、专业搜救人员和指挥员重新评估。
