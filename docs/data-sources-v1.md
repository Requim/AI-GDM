# AI-GDM 数据来源 v1

## 数据原则

- 动态数据只从真实互联网接口获取，不生成模拟实时事件。
- 每份数据保存供应商、数据集、获取时间、有效期、修订或摘要等溯源信息。
- 供应商失败时，最后成功数据超过有效期后必须显示过期或不可用，不能冒充当前；仅损失模块可在 72 小时有界窗口内将完整旧投影用于很低置信度研究参考。
- 测试夹具、演示基线和公开历史回放必须与实时数据明确区分。

## 来源清单

| 来源 | 用途 | 调用方式 | 默认时效/触发 | 认证与费用边界 |
| --- | --- | --- | --- | --- |
| NASA Earthdata GIS `LHASA_Hazard_Today` | 全球滑坡近实时危险度栅格 | ArcGIS ImageServer，服务端发现分片并下载 | 调度器默认每 30 分钟检查；组合修订首次发现后默认 12 小时过期 | 当前公开读取无需业务 Key；网络或合同变化会降级 |
| Open-Meteo Forecast API | 降雨、五层体积含水率等气象上下文 | 服务端批量点位请求 | 默认成都、昆明两个可配置点，72 小时历史、24 小时预报；最后成功结果最多回退 6 小时 | 默认公共端点可无 Key；不作为全国气象网格或现场观测 |
| geoBoundaries gbOpen CHN ADM0 | 风险处理范围和暴露空间裁剪依据 | 固定元数据与内容寻址的简化几何下载 | 每次新风险刷新先校验；新暴露投影按同一边界身份校验 | 当前合同年份 2019、许可 `Public Domain`；只提供 ADM0，不是省市县数据，也不是中国官方或法定国界依据 |
| WorldPop Global 2 | 风险区域年度 100m 人口汇总 | 服务端创建任务并轮询结果 | 新空间分析缺少当前暴露投影时按需获取，数据年取采集时 UTC 年份 | 当前公共任务接口；响应不能独立证明配置 URN，系统会保留该限制 |
| OpenStreetMap Overpass | 道路、医院、避难设施等暴露要素 | 服务端 Overpass QL 请求 | 新空间分析缺少当前暴露投影时按需获取 | 公共服务；超时、部分结果、坏几何或不可分类元素均不得静默接受 |
| 高德 Web 服务 | 候选 POI、逆地理信息和多方式路线 | 服务端代理 Web Service API | 用户发起疏散查询时实时调用 | 需要服务端 Web 服务 Key；Key 不下发浏览器；配额和许可以高德账户为准 |
| 博查 Web Search | 灾害公开信息证据 | 服务端受限关键词搜索 | 用户请求 AI 解释时按需调用 | 需要 API Key；只保留可信域、有界、去标识化证据 |
| OpenAI 兼容 LLM | 对确定性结果生成中文解释 | 服务端 Chat Completions 兼容接口 | 用户请求 AI 报告时按需调用 | 需要 API Key；不可修改确定性数值，供应商失败时保留 Authority 并降级 |
| USGS 公开案例页面 | 历史案例目录的事实来源 | 发布版本内的匿名化审计快照与公开链接 | 固定历史回放，不声明实时刷新 | 不包含姓名、电话、证件号或详细地址 |

## 空间与坐标

- 数据库与服务端分析统一使用 WGS84。
- 高德 Web 服务使用 GCJ-02；转换只在高德适配器边界执行。
- 风险栅格先按 WGS84 中国外接矩形 `[73.5,18.0,135.1,53.6]` 下载和分级，再按固定版本的 geoBoundaries gbOpen CHN ADM0 简化边界执行精确矢量裁剪。外接矩形只是数据获取预筛选，不是最终统计范围。
- 风险制品 SHA-256、转换版本、边界 ID、边界版本、来源摘要和规范几何摘要共同参与快照身份；页面显示的总数只统计该快照边界内的风险区，地图最多绘制 3000 个高优先级风险区。
- 人口、道路和设施暴露通过全局 feature ID 与风险区绑定去重，投影身份绑定来源、有效期和内容摘要。

每次生成新风险快照前先获取并校验 geoBoundaries 边界，再进行 GDAL 裁剪并把边界身份写入快照。风险快照保存确定性面积分析后，若同一空间分析缺少当前暴露投影，再复核 geoBoundaries 边界并触发 WorldPop 和 Overpass 采集；暴露投影必须与风险快照使用同一边界身份。暴露供应商失败不会删除已经保存的风险结果；当前投影不可生成时优先返回数据不足，已有完整投影刚过期且不超过 72 小时时只能生成明确标记的最后成功数据研究参考区间。

## 降级口径

- LHASA 或 Open-Meteo 本次刷新失败：仍有效的最后成功数据可标记 `fallback/stale` 后继续展示；过期后不再作为当前结果。损失模块可在过期后 72 小时内读取同一最后成功风险与暴露投影，但只能返回 `reference_only / very_low`，超过窗口后不可用。
- geoBoundaries 在风险刷新前不可用：仅可沿用仍有效的最后成功风险快照，并明确标记边界身份本次未复核；若已发现边界版本或摘要变化后新处理失败，则禁止回退到旧范围。
- WorldPop、Overpass 或暴露阶段的 geoBoundaries 校验失败：不生成新的当前暴露投影；没有 72 小时窗口内同一空间分析的完整投影时，损失评估返回数据不足。
- 高德失败或返回坏数据：候选设施或路线不可用，不使用本地伪造路线替代。
- 博查失败：AI 报告可保留确定性 Authority，证据数组为空并明确限制。
- LLM 失败：不返回伪造解释，确定性卡片仍保持不变。

## 外部合同风险

公共服务的端点、字段、配额和许可可能变化。适配器对未知字段、重复关键键、重定向、响应大小、几何复杂度和不一致状态执行 fail-closed 校验；上线值守仍需监控供应商状态并及时升级适配器。
