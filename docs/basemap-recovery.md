# 底图加载恢复

## 来源与边界

- 风险区仍来自服务器保存的 NASA 快照，本次不修改风险计算、坐标、数据库或快照。
- 底图改用 OpenTopoMap 官网列出的备用栅格服务 `https://backup.opentopomap.org/{z}/{x}/{y}.png`，风险地图与疏散地图共用。
- 按官网备用图层约束，原生缩放范围为 1 至 15；15 级以上仅放大现有瓦片，不伪装更高精度或请求不存在的层级。
- 保留 OpenStreetMap、SRTM、OpenTopoMap 与 CC-BY-SA 署名。只请求当前视口及小缓冲范围，不批量预下载、不建立全国镜像。
- 公共备用底图不提供可用性保证，数据时效未确认，不是官方地图、实时道路或道路可通行证明。正式业务底图需另行落实服务保障和地图使用要求。
- 来源说明：`https://opentopomap.org/about`，服务地址与原生层级见 `https://opentopomap.org/`。

## 故障处理

- 已复现旧 OpenStreetMap 瓦片在用户应用内浏览器和腾讯服务器连接超时。
- 候选 CARTO 栅格可达，但官方文档现要求独立 Key 并提示退役计划，因此未接入免 Key CARTO 或规避其水印。
- 部分瓦片失败时持续提示降级，不再因另一张瓦片成功而掩盖失败。
- 后续缩放重新监测超时；风险页“重新读取”也会重试底图。底图失败不会清除风险区或更改风险状态。
- 每张失败瓦片最多自动重试两次；成功、移出视口或销毁地图时取消重试，不无限刷新、不附加缓存破坏参数。
- CSP 仅为图片新增明确备用来源，不开放外部脚本或通用网络访问；不传输 API 密钥。
