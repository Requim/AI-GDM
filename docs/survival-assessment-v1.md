# 生还可能性辅助评估 v1

## 计算边界

评估只接受 `Synthetic=true` 的匿名搜救场景。规则从 50 分开始，根据失联时长、输入完整度、可呼吸空间、饮水、危险源稳定性、重伤信号和通信状态进行固定加减分，再把 0 到 100 分映射为宽概率区间和搜救优先级。

规则版本固定为 `ai-gdm-survival-rules-v1`。相同场景和同一计算时间会得到相同结果；输出包含评分、概率带、优先级、主要因素、模型版本和人工复核状态。

## 科学限制

- 概率是辅助研判的宽区间，不是经临床或个体数据校准的生还概率。
- 历史案例存在报告偏差，不能从事件级数据外推到具体人员。
- 规则不读取或推断姓名、伤情诊断、医疗记录等敏感个人信息。
- 现场危险源、伤情、通信和天气变化必须由有资质的搜救人员重新确认。

任何评估结果都不能作为自动停止搜救、医疗分诊或替代指挥员判断的依据。
