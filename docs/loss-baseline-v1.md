# 损失评估基线 v1

P5.1 只建立基线数据契约和持久化能力，不在仓库内内置人口、道路、资产价格或脆弱性数值。导入方必须提供可审计的真实数据集，并在每条记录的 source 中记录供应商、数据集版本、修订、引用、许可、抓取时间、有效期、转换版本、质量标志和 SHA-256。

## 数据范围

- 人口暴露：区域编码、人数、数据年份和覆盖率，单位固定为 people。
- 道路暴露：区域编码、道路长度、数据年份和覆盖率，单位固定为 meters。
- 资产成本：建筑、道路或设施的人民币单位重置成本低/中/高情景，金额使用人民币分。
- 脆弱性：灾种、强度带、影响比例和损伤率低/中/高情景。

## 版本与时效

BaselineSet.Version 必须与每条来源的 DatasetVersion 一致；人口、道路、成本和脆弱性四类记录必须同时存在，写入通过单个数据库事务原子替换。读取端口只返回当前 UTC 时刻有效且同一最新数据集版本的记录；没有有效记录时返回 domain.ErrNotFound，由上层用例转换为 insufficient_data，不得用零值冒充缺失数据。

## 远端验证

在腾讯 Ubuntu 验证服务器执行：

    sudo sh scripts/validate-baseline.sh

脚本启动临时 PostGIS，执行基线领域与仓储测试（含 race 重复运行）、迁移校验、go vet ./... 和 go build ./...。
