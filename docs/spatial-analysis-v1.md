# AI-GDM 空间分析规则 v1

## 定位

本规则对已经保存为 WGS84 的完整风险区集合进行确定性空间分析。规则版本固定为 `ai-gdm-spatial-analysis-v1`。基础分析计算风险区去重地表面积；随后由暴露采集链以同一空间分析身份获取 geoBoundaries、WorldPop 和 OpenStreetMap Overpass，形成不可变的人口、道路和设施投影。

## 输入边界

- 输入必须是 `analysis_complete=true` 的灾害快照及其全部风险区；暴露投影还必须精确绑定本次空间分析 ID 和摘要。
- 风险区只接受有效、非空的 `Polygon` 或 `MultiPolygon`，不静默修复非法几何。
- 数据库存储坐标系固定为 WGS84；面积计算不经过高德 GCJ-02 转换。
- 计算时间由应用层以 UTC 显式传入，适配器不自行读取系统时间。

## 面积规则

- 单区面积由 PostGIS `geometry::geography` 计算，单位为平方米。
- 总面积先合并全部风险区再计算，重叠部分只计一次。
- 完整快照没有风险区时，总面积为零，并返回已完成的 `area_only` 结果。
- 每个风险区几何生成 SHA-256 输入引用；同一规范化输入生成稳定分析标识，执行时间不参与标识。

## 数据缺失语义

- `available` 表示真实图层完整覆盖风险区，数量可以是真实零值。
- `partial` 表示真实图层只覆盖一部分风险区，必须提供覆盖率、来源和限制。
- `unavailable` 表示没有可计算的真实图层，数量和覆盖率必须为 `null`，不能写成零。
- 基础面积分析可以在暴露供应商不可用时保持完成；人口、道路或设施投影失败时不伪造零值，损失链返回数据不足。
- 当前生产暴露链只在 geoBoundaries、WorldPop 与 Overpass 全部通过合同、来源、有效期和资源预算后把投影标为 `available`。非闭合设施 way 等被跳过项必须进入限制说明。

## 持久化与一致性

- 基础空间分析头和区级结果在 Repeatable Read 事务中计算、保存并回读校验；暴露投影使用独立 Serializable 事务按 `incomplete -> features/bindings -> complete` 固化。
- 执行器先锁定完整快照，保证计算期间风险区集合一致。
- 同一快照重新写入风险区时，旧空间分析在同一事务中失效，避免留下只有头记录的残缺结果。
- 数据库迁移使用事务级 advisory lock，支持多个进程或测试包并发启动。
- 人口、道路和设施以有界 feature ID 保存，跨重叠风险区使用唯一 feature 与 zone bindings，避免损失层重复计费。
- 任一区级结果或暴露投影写入失败时对应事务全部回滚，不影响已经保存的基础 LHASA 风险结果。

## 当前限制

面积是几何模型结果，不等同于实际受灾面积。WorldPop 是年度人口模型，OpenStreetMap 覆盖可能不完整，geoBoundaries 当前只提供 ADM0 裁剪边界；暴露投影不能替代现场清点，也不会用模型猜测或固定系数填充缺失值。
