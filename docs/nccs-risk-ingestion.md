# NCCS 风险采集与单快照保留

## 当前行为

当前源码默认使用 NASA NCCS Portal 近实时目录，不再通过已失效的 Earthdata ImageServer 导出分片。
既有发行包与生产容器不会自动更新，必须重新构建、验收后部署。

处理顺序：

1. 获取真实目录，选择同源、同目录且时间格式有效的近实时 TIFF，拒绝预报和外站链接。
2. 固定 URL、强 ETag、Last-Modified 与长度，以 1 MiB 分段、最多四路下载完整文件。
3. 分段携带 If-Match 并校验 206、Content-Range 和 ETag；异常保留断点，完成段保存 SHA-256。
4. 重启后恢复未完成下载；同版本完整文件重新校验摘要后复用。下载前后均复核源版本。
5. 本地 GDAL/Python 全像元检查，裁剪中国外包范围，NaN 转为 NoData=-9999，原生行序翻转为北向上，不插值概率。
6. 沿用项目的版本化 CHN ADM0 边界、概率阈值、矢量化和分级区域统计，形成可追溯风险快照及风险区。
7. 在同一数据库事务内保存新快照及全部风险区，再删除同灾种、同模型的其他快照；任何一步失败整批回滚。
8. 数据库提交后回收旧原始 TIFF、来源侧车文件和过时下载目录。清理失败记录警告，后续成功刷新或同版本复用时重试。

“获取成功”的提交边界是下载、栅格处理、风险区校验和快照事务成功。
后续暴露数据采集仍可能独立失败，不能因为风险快照成功就宣称人口、道路或损失估算可用。

## 保留与回退

- 稳定状态只保留当前滑坡模型最新一次风险快照。更新过程中允许旧快照与尚未提交的候选制品暂存。
- 下载、版本检查、GDAL、边界读取或数据库提交失败均不删除上次快照。
- 边界更新时先完成新范围处理，再替换旧快照；失败回退明确携带旧边界限制。
- 同一文件版本不会重复生成快照或刷新首次发现时间；不允许较早发布的数据覆盖较新的同源数据。
- 旧快照的风险区、固化风险评估、空间分析及其暴露投影一并回收；已保存的独立历史损失业务记录不删除。
- 普通 SQL 删除上游数据或修改已完成投影的不可变保护仍在。只有替换事务能为明确的旧分析设置事务内回收标记。
- 被删除的快照 ID 不再支持风险详情和地图回放；客户端应重新获取最新快照，不得自动将旧 ID 解释为新快照。
- 过期数据保留不等于可继续按实时数据使用；既有过期、不可用和降级规则继续生效。
- 原始文件清理仅操作独立 LHASA 制品目录中可验证的侧车文件，不递归清理其他项目目录。

## 配置

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `REFRESH_ENABLED` | 沿用原配置 | 是否启动后台刷新 |
| `LHASA_PORTAL_URL` | NASA Portal `/datashare/landslides/nrt/hazard/tif/` | 近实时目录 |
| `LHASA_REFRESH_INTERVAL` | `2h` | 上一轮结束后的间隔 |
| `LHASA_REFRESH_TIMEOUT` | `70m` | 风险采集整轮时限，须小于刷新间隔且不超过 2h |
| `LHASA_STALE_AFTER` | `12h` | 本系统来源使用期限，不是模型预测覆盖期 |
| `LHASA_DATA_DIR` | 沿用原配置 | 完整原始制品及 `.nccs-downloads` 断点目录 |
| `GDAL_TEMP_DIR` | 沿用原配置 | 本地裁剪与矢量化临时目录 |

完整文件下载自身最多运行 60 分钟；单个 Range 请求最多 90 秒，最多六次有限重试。
天气采集继续使用原 `REFRESH_INTERVAL`、`REFRESH_TIMEOUT`，与风险长任务独立。
旧 `LHASA_EARTHDATA_URL` 已不再控制服务器风险采集入口。
`cmd/lhasa-fetch` 同样使用 Portal，但只做制品下载，不更新数据库或删除生产快照；手工运行应使用独立 `LHASA_DATA_DIR`。

## 数据口径

- 目录文件算法版本未在元数据中确认，不冒充特定 LHASA 算法版本。
- 文件名作为来源标识；模型运行时间和观测时间保持未知。
- `PublishedAt` 记录 HTTP Last-Modified；有效期是本系统从发布时间计算的可使用期限，并明确标记不是 NASA 模型覆盖期。
- 中国预裁剪范围为 `[73,3,136,54]`，向外对齐原生网格，随后按既有 CHN ADM0 数据精确裁剪。
- CHN ADM0 公共边界不是中国法定国界或官方地图依据；数据缺失不代表零风险。
- 原始 SHA-256 对应完整下载文件；新处理版本记录方向/缺失值规范化及边界约束，避免混用旧处理结果。
