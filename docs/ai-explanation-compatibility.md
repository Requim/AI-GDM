# AI 解释兼容性与可读性

## 变更范围

- 公开来源的有效期可以覆盖未来；观测、发布和修订发现时间不得晚于该来源的获取时间。仍要求合法 UTC 日期，并拒绝倒置有效期。
- 仅兼容完整 JSON 外的单层 `json` 或无语言标记代码围栏。仍拒绝额外文字、多段 JSON、未知字段、缺失字段、null、错误类型和超长输出。
- 不改变公开来源最小化、权威摘要验证、数值范围、字段白名单、前端文本安全渲染及旧结果失效清理。
- 时间错误改为具体中文原因，并说明原始评估结果未改变；不会用伪造说明替代失败结果。

## 面向普通读者的提示词

- 摘要先回答“这份结果意味着什么”，再说明最重要的限制。
- 依据解释因素如何影响理解，建议指向具体的人工核对事项。
- 使用短句，避免字段名、内部编号、哈希和其他技术术语。
- 区分假设灾害发生后的直接损失与必然损失，区分历史研究回放与当前灾情、个人生还预测。
- 资料不足时说明缺口与无法判断的内容；不能将搜索证据的去标识化占位文字说成真实报道。
- 不生成新的数值，不修改确定性结果。提示词是生成引导，不构成模型永远正确或人人易懂的保证。

## 验证

- 仅在腾讯 Ubuntu 隔离目录验证，不连接业务数据库或缓存，不替换生产应用。
- 新增 Go 测试覆盖完整围栏兼容、尾随文字与多段 JSON 拒绝、核心字段和 null 拒绝、可读性与安全提示词约束。
- 新增六项 Chromium 测试覆盖搜索证据与模型来源的未来有效期、非法日期、事件时间超前、倒置有效期，以及失败后原始回放结果保留。
- 验证结果以本阶段 PROGRESS 记录为准；夹具和提示词断言不等于真实模型输出质量验收。
- 真实供应商单次样例调用：使用独立容器和明确标注的合成历史研究输入，未使用真实人员数据、未写入业务结果。结构校验通过，返回了“不是当前灾情，也不能用来预测个人生还情况”等限制及具体人工核对建议。
- 人工阅读仍发现“整体判断偏低”等模糊表述。此次改进降低了技术术语密度，但不保证每次输出都准确易懂，不替代人工复核，也不等于完整生产链路或真实灾情验收。
