# 局部热点道路损失参考方法 v1

## 目的

该方法用于 AI-GDM MVP 在缺少完整、已批准成本与脆弱性基线时，仍能对真实采集的局部道路暴露给出可审计的人民币参考区间。它不是全国灾损估计、法定核损结果或政府发布数据。

当前风险和暴露投影有效时，正式基线始终优先。只有 PostgreSQL 基线读取器明确返回“未找到完整基线”时，服务才使用本方法；数据库异常、超时、内容损坏和缺少道路暴露仍然 fail-closed。

风险或暴露投影过期但仍在 72 小时降级窗口内时，服务不会继续生成正式 `available` 评估，而是强制使用本研究参考基线。该路径不读取正式基线金额，输出固定为 `reference_only`、`very_low`，置信度最高 `0.24`，并写入“最后成功数据、不代表实时情况”的强制限制。超过 72 小时后仍返回数据不足。

## 局部范围选择

范围策略固定为 `highest-risk-window-v1`：

1. 只读取当前空间分析绑定的风险区。
2. 风险等级按 `very_high > high > moderate > low` 排序。
3. 同等级按声明面积降序、风险区 ID 升序选择种子。
4. 使用种子面的 `ST_PointOnSurface` 为中心，构造 `0.05° × 0.05°` WGS84 窗口。
5. 对相交风险区做几何裁剪，最多保留 10 区；WorldPop、OpenStreetMap、行政边界和最终损失读取均使用同一裁剪集合。
6. 范围策略、种子、窗口、区数、面积覆盖率和所选区 ID 共同进入内容摘要，并在评估限制中公开。

面积一致性校验允许 1% 的投影和舍入误差，但不允许用容差补造缺失的道路、人口或设施。

## 道路参考区间

参考来源为 2024 年发表的西藏吉隆藏布流域泥石流经济风险研究：

- 三级道路：`83,460 EUR/km`，脆弱性 `0.65`。
- 四级道路：`46,320 EUR/km`，脆弱性 `0.85`。
- 文章 DOI：`https://doi.org/10.1007/s13753-024-00545-x`。

汇率使用欧洲中央银行 2024-03-01 参考数据 `1 EUR = 7.7837 CNY`：

- ECB 数据端点：`https://data-api.ecb.europa.eu/service/data/EXR/D.CNY.EUR.SP00.A?startPeriod=2024-03-01&endPeriod=2024-03-01`。

由于当前 OSM 暴露投影不能可靠区分道路等级，v1 使用两个案例条件损失值构造包络：

- 低位：四级道路条件损失，`30,646` 分/米。
- 高位：三级道路条件损失，`42,226` 分/米。
- 中位：上述两值的算术中点，`36,436` 分/米。

上述金额已经包含论文道路类别对应的案例脆弱性，因此公式中的研究参考脆弱性固定为 `1/1/1`，只用于避免重复乘算，不代表所有风险等级具有相同物理脆弱性。

## 输出合同

- 评估状态：`reference_only`。
- 基线状态：`demo_only`。
- 基线层级：`reference_case`。
- 计价资产：仅 `road`。
- 人口与设施：继续显示实际暴露背景，但不进入金额。
- 置信度：最高 `0.49`，只能显示为低或很低。
- 最后成功数据：置信度最高 `0.24`，只能显示为很低；浏览器在 `validTo + 72h` 自动撤销快照绑定。
- 必须显示局部范围、仅道路、跨区域外推、历史汇率和辅助研判限制。

任何正式 `approved` 基线与研究参考基线混用、任何设施参考价格、来源错绑或状态篡改都会被服务端和浏览器共同拒绝。
